ZARA AURA — MACHINE LEARNING DATASETS (synthetic, generated by generate_data.py)
================================================================================

1) recommendation_dataset.csv  — 10,000 rows — CLASSIFICATION (Random Forest Classifier)
   Features: cust_gender, cust_size, cust_skin_tone, cust_pref_color, cust_occasion,
             prod_category, prod_subcategory, prod_material, prod_color, prod_price
   Target  : liked   (0/1)     [customer_id is an identifier, not a feature]

2) sales_dataset.csv  — 730 rows (2 years daily) — REGRESSION (Random Forest Regressor)
   Features: day_of_week, day_of_month, month, day_of_year, is_weekend, is_festival, day_index
   Target  : revenue         [date, orders are context columns, not model features]

3) stock_dataset.csv  — 8,320 rows — REGRESSION (Random Forest Regressor)
   Features: prod_category, prod_subcategory, prod_price, month, week_of_year,
             is_festival_week, units_sold_last_week, avg_sales_4wk, current_stock
   Target  : units_sold_next_week

TRAIN/TEST SPLIT: 80% / 20%, train_test_split(test_size=0.2, random_state=42).
   Recommendation split is stratified on 'liked'. Regression splits are not stratified.

PREPROCESSING (scikit-learn ColumnTransformer inside each model pipeline):
   - Missing categorical -> "Unknown"; missing numeric -> column median (sales feats -> 0).
   - Categorical -> OneHotEncoder(handle_unknown="ignore").
   - Numeric     -> StandardScaler.
